# GlowNest

A skincare website with routines, products, a skin quiz and a contact form. A student project for the **Web Programming** course at the ICT College of Vocational Studies in Belgrade.

**Live demo:** https://minajevtic7523.github.io/GlowNest/

## Features
- Typing effect in the hero section, smooth scrolling, back-to-top button
- Product gallery and a testimonial carousel
- Skin quiz that recommends products based on skin type and concern
- Contact form and newsletter form with validation
- Responsive layout

## Built with
HTML5, CSS3, JavaScript, jQuery, Slick carousel, Font Awesome

## Files
`index.html`, `about.html`, `index.css`, `main.js`, `sitemap.xml`, `slike/` (images)

## Note
GlowNest is a demo. The testimonials and product names are made up for the project.
